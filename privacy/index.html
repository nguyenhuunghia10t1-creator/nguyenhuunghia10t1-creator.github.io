Privacy Policy

Last updated: 2 October 2026

Website scope

This policy describes information handling on verdefsoft.me, an informational website for VerdefSoft Technologies Co., Ltd.. The site has no user accounts, checkout or analytics added by VerdefSoft Technologies Co., Ltd..

Project inquiry drafts

The contact form creates an email draft locally in your browser. Form content is not submitted to a VerdefSoft Technologies Co., Ltd. backend and is not saved to browser storage by this website. Copying the draft puts that content on your device clipboard; opening the email link passes it to your configured email application.

Email inquiries

If you send an email, the receiving email service and VerdefSoft Technologies Co., Ltd. receive the details you choose to include, such as your name, company, contact details and project description. Those details are used to respond to the inquiry and discuss the requested work. Avoid sending passwords, credentials or sensitive project material in an initial inquiry.

Hosting and third-party services

This website is hosted on GitHub Pages. GitHub states that visitor IP addresses are logged and stored for security purposes. See GitHub Pages data collection and the GitHub Privacy Statement. Your email provider handles messages according to its own policies.

Cookies and local storage

The site code does not set cookies, use local storage for inquiry content, load advertising or include third-party tracking scripts. The site loads its visual assets from this domain.

Questions and requests

For questions about inquiry information or to request a correction or removal, email contact@verdefsoft.me. Requests are assessed against the records available and applicable obligations.

Updates

This page will be updated if the website’s information-handling features change. The date above identifies this version.
